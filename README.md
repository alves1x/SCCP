Este projeto é um site simples criado para pesquisar jogadores do Corinthians. Desenvolvido durante um curso da Alura , o foco principal foi praticar **JavaScript** para a lógica e **CSS** para estilização
Funcionalidades do sistema:
- Permite buscar jogadores do Corinthians por nome.
- Exibe informações de forma clara e organizada.
- Design responsivo e estilizado com CSS.
